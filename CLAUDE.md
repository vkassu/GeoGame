# GeoGame

GeoGame — браузерная игра-викторина по географии мира. Референс: Geography of the World (Atom Games Ent.). Цель: угадывать страны по контуру на карте, флагам, столицам, населению.

## Стек

Чистый HTML/CSS/JS, ES-модули, никаких фреймворков, никакого npm. Запуск через локальный сервер или Live Server (модули не работают через `file://`). Деплой на GitHub Pages: https://vkassu.github.io/GeoGame/

## Данные

restcountries.com API (v3.1). Запрос требует параметр `?fields=...`, иначе вернёт 400. Данные стран загружаются на лету при старте (кеш в `data/countries.json` пока не реализован). Язык интерфейса — русский; названия стран берутся из `translations.rus`.

Столицы API отдаёт **только по-английски**, поэтому русские названия столиц лежат в отдельном файле данных `data/capitals_ru.json` (ключ — код страны `cca2`) и подгружаются в `fetchCountries`. Словарь покрывает все 246 столиц из API, поэтому страны из игры не исключаются — играется полный список. `capitalName` берёт русское название из словаря (с фолбэком на английское из API, если страну вдруг добавят новую).

## Структура проекта (фактическая)

- `index.html` — единственная страница: экраны старт / игра / результат, переключаются классом `.active`.
- `css/style.css` — все стили.
- `js/data.js` — слой данных: запрос к API и геттеры полей страны (`ruName`, `capitalName`, `hasCapital`, `population`, `codeToEmoji` и т.д.). Без DOM и без игровой логики.
- `js/main.js` — точка входа: игровой `state`, конфиг режимов `MODES`, логика вопросов, единственное место работы с `localStorage`.
- `js/ui.js` — слой представления: переключение экранов и заполнение DOM. Без игровой логики и без state.
- `data/capitals_ru.json` — словарь русских названий столиц (`cca2` → название).

Разделение `main.js` / `ui.js` заменяет изначально планировавшийся `js/game.js`.

### Пока не реализовано (из исходного плана)

- `data/countries.json` — кеш данных в файле (сейчас всё тянется из API).
- `assets/world.svg` — карта Natural Earth для режима «по контуру».
- `game.html` — отдельной страницы нет, всё в `index.html`.

## Жёсткие ограничения

- Никаких фреймворков.
- Никаких платных API.
- Всё работает в браузере без бэкенда.
- Данные не вшивать в JS-код.
- Не делать всё в одном файле (слои data / ui / логика разделены).

## Режимы игры

Реализованы (выбор режима — на стартовом экране, под заголовком «Выбор режима»; выбор сложности — под заголовком «Выбор сложности»):

1. **Угадай страну по флагу** (`country`) — показывается флаг, выбрать название страны из 4 вариантов.
2. **Угадай столицу по флагу** (`capital`) — показывается флаг, выбрать столицу из 4 вариантов.
3. **Угадай страну по столице** (`countryByCapital`) — показывается название столицы, выбрать страну из 4 вариантов.

Рекорды хранятся отдельно для каждого режима (`geogame:bestScore:<mode>` в localStorage).

Сложность (общая для режимов): лёгкая — 5 вопросов, средняя — 10, сложная — 15.

Сквозная кнопка «На главную» (в шапке) видна на экранах игры и результата (скрыта на стартовом). Во время идущей партии перед выходом запрашивает подтверждение.

### Запланированные режимы

- Угадай страну по контуру (нужна SVG-карта).
- Угадай по населению.

## Соглашения в коде

- `state` и `localStorage` — только в `main.js`. UI-слой не знает про state.
- Ключи localStorage: `geogame:bestScore:<mode>`, `geogame:difficulty`, `geogame:mode`, `geogame:gamesPlayed`.
- Новый режим добавляется как запись в объект `MODES` (`startTitle`, `subtitle`, `question`, `prompt`, `answer`, `valid`) — остальная механика обобщена и переиспользуется.
- `prompt(country)` возвращает дескриптор того, что показывать в вопросе: `{ type: "flag", country }` или `{ type: "text", text }`. `renderQuestion` в `ui.js` рисует флаг или текстовый блок по этому типу.
