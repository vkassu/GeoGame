# GeoGame

GeoGame — браузерная игра-викторина по географии мира. Референс: Geography of the World (Atom Games Ent.). Цель: угадывать страны по контуру на карте, флагам, столицам, населению.

## Стек

Чистый HTML/CSS/JS, никаких фреймворков, никакого npm. Запуск через локальный сервер или Live Server. Деплой на GitHub Pages.

## Данные

restcountries.com API, кешируются в `data/countries.json`. Карта — SVG (Natural Earth). Язык интерфейса — русский.

## Структура проекта

- `index.html`
- `game.html`
- `css/style.css`
- `js/main.js`
- `js/data.js`
- `js/game.js`
- `data/countries.json`
- `assets/world.svg`

## Жёсткие ограничения

- Никаких фреймворков.
- Никаких платных API.
- Всё работает в браузере без бэкенда.
- Данные не вшивать в JS-код.
- Не делать всё в одном файле.

## Режимы игры (в порядке реализации)

1. Угадай страну по контуру.
2. Угадай по флагу.
3. Назови столицу.
4. Угадай по населению.
